# StageCue — 现场歌词提词器

一个纯静态、离线可运行的 iPad 横屏现场歌词提词网页。

## 功能

- 导入 `.lrc` 歌词文件，支持 `[mm:ss.xx]歌词` 时间戳
- 编辑歌词、时间戳，或直接粘贴 LRC 内容
- 字号、行距、提前显示秒数可调
- 演出模式自动按时间轴滚动；字号过大时自然滚动
- 直接点任一句歌词，立即跳转到该句对应时间，适合现场纠正进度
- 上一句、下一句、暂停、重置、全屏与屏幕常亮（设备支持时）
- 自动保存歌词和设置到当前设备浏览器；没有网络也能使用

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库，例如 `stagecue`。
2. 把本文件夹中的 `index.html`、`style.css`、`app.js` 上传到仓库根目录。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 里选择 **Deploy from a branch**，选择 `main` 与 `/ (root)`，保存。
5. 等待约一分钟，GitHub 会提供访问链接。iPad 用 Safari 打开后，横屏使用；也可“添加到主屏幕”。

## LRC 示例

```lrc
[00:05.00]第一句歌词
[00:09.20]第二句歌词
[00:14.00]第三句歌词
```

演出中的“提前显示”会让歌词比它的时间戳更早高亮。比如设置 `1.5 秒`，标记为 `00:10.00` 的歌词会从 `00:08.50` 开始显示。
